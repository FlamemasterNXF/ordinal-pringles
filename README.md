# Ordinal Pringles

Ordinal Pringles was inspired by the popular incremental game Ordinal Markup.

Despite this initial inspiration, it has been completely rebuilt from the ground up with nearly every feature radically changed or expanded upon. On top of these changes, there are a plethora of new features including an entirely new prestige layer (and there's no Incrementyverse).

All of these changes and additions have resulted in a game larger, more polished, and less timewall filled then Ordinal Markup - a true spiritual successor to the concept.

Grow your Ordinal from the lowly ω to unimaginably huge heights, unlock a multitude of ever-expanding and unfolding features, and progress through several huge prestige layers as you approach the end of infinity.
